# Hook research: source audit and adopted tests

## Inspected sources
- https://raw.githubusercontent.com/SkillMedev/creator-studio/main/skills/youtube-script-writer/SKILL.md — read full skill, not installed or executed. Useful beat structure: mini-promise, delivery, bridge; title/opening alignment and explicit visual notes. Reject as unproven universal claims: midpoint always second-largest drop, mandatory interrupts every 90–120 seconds, mandatory bonus ending, and sweeping algorithm assertions. Its own scope excludes voiceover synchronized to tutorial actions; do not adopt it wholesale for CJ's screen-led tutorials.
- https://github.com/rahulanand1103/youtube-script-writer — inspected README architecture only, not source-code verified or execution-tested. Outline -> research -> refined outline -> per-section writing is a useful separation. README claims of accuracy/coherence are marketing, not evaluated results. Add a whole-script continuity pass; section generation is not sufficient editorial QA.
- https://support.google.com/youtube/answer/16391400?hl=en — primary documentation: eligible desktop Studio creators can test up to three title/thumbnail variants; winner based on watch time, not CTR alone. Tests may be inconclusive; available impressions matter. These tests do NOT test alternate spoken intros. Check account eligibility before offering execution; never publish/change channel assets without approval.
- https://support.google.com/youtube/answer/9314415?hl=en — primary retention guidance, retained in numbered-series-hooks.md.

## Adopted editorial tests
1. First-frame test: identify a specific visible object/result/problem before choosing effects. A title card alone is packaging, not necessarily a visual hook.
2. Sound-off test: is the topic or tension legible from the first visual and short text? Do not require the entire lesson to be understood silently.
3. Audio-only test: does the spoken opener make sense without reading the screen? Necessary UI-dependent directions belong after context.
4. Promise match: title, thumbnail, first spoken lines, first visual, demonstration and ending must agree.
5. First-useful-moment test: give an actual example, result, or actionable distinction early; no arbitrary universal second threshold.
6. Distinct-item test: numbered points must solve meaningfully different cases. Number comes from verified content before final packaging.
7. Bridge test: each next item answers a new need ('That finds one person. What if you need everyone who...?'), not a repeated 'next up'. Avoid invented feature behavior.
8. Filmability test: require real demo assets or label conceptual illustrations. Never describe a visual as produced until rendered/reviewed.
9. Controlled learning: keep draft hypothesis, CJ preference, recording observation and audience outcome separate. Do not call editorial rubric scores retention predictions.

## Hook lab template
Working title; source/angle from Pizza wheel; one viewer situation; three alternate openings (result/problem/contrast); for each: spoken words, screen text, first frame, edit action, first payoff, proof required. Select one by editorial judgment and say why. No auto-install of third-party skills.
